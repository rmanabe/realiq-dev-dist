リアルIQ測定 — 実機テスト用

iPhone の Safari で開いてください。ビルドは2種類あります。

1. 単体で動くビルドおすすめ

JavaScript を焼き込んであるので、PC も Wi-Fi も要りません。 入れたらホーム画面のアイコンを押すだけで動きます。16分の通しを測るならこちらです。

これをインストール

広告は Google のテスト広告、課金の導線は出ません（キーを設定していないため）。 検査そのもの・時間制限・結果・見直しは本番と同じです。

2. 開発ビルドJSの修正をすぐ試す用

PC の開発サーバーから JavaScript を読みます。直した内容がビルドを待たずに 端末へ届きますが、PC が起動していて同じ Wi-Fi にいることが必要です。

開発ビルドをインストール

入れたあと、Safari で次を開いて接続します。

開発サーバーに接続（192.168.11.14:8081）

IP とポートは起動のたびに変わりえます。変わったときは次の形で開いてください。

http://<PCのIP>:<ポート>/_expo/link?platform=ios&choice=expo-dev-client

  • &choice=expo-dev-client を省かないこと。 省くと Expo Go 用のURLへ転送され、Expo Go は使えないのでエラーも出ずに何も起きません
  • 設定 → プライバシーとセキュリティ → ローカルネットワーク で、このアプリを ON にし、 アプリを完全終了して起動し直す（iOS はこの変更を再起動まで反映しません）
  • iPhone と PC が同じネットワークにいることを、IPアドレスの数字で確かめてください

2つは同時に入りません

どちらも同じアプリID（com.robonetcommunications.realiq）なので、 あとから入れたほうが前のものを置き換えます。 切り替えたいときは、もう一方をインストールし直してください。

入らないとき

  • Safari で開いていますか（Chrome など他のブラウザでは動きません）
  • 前に失敗した残骸がホーム画面に残っていませんか。残っていたら先に削除してください
  • 「信頼されていないデベロッパ」と出たら、設定 → 一般 → VPNとデバイス管理 から許可します
  • どちらも ad hoc 署名です。登録された端末にしか入りません （他の端末では署名の検証で弾かれます）
